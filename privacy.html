Privacy policy

lkml-yt is a private tool that uploads videos to the LinuxKernelToday YouTube channel. Only the channel's owner signs in to it.

What it accesses

With the YouTube permission the owner grants, it reads the channel's name and ID, uploads videos, and changes their privacy setting (private to public). It doesn't read or change anything else on the account.

What it stores

The Google refresh token and the channel's name and ID, in a file on the owner's own server that only the owner can read. It isn't sent anywhere except back to Google to get access tokens. Nothing is shared with, sold to, or used by anyone else, and nothing is used for advertising.

lkml-yt's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Disconnecting in lkml-yt revokes the token at Google and deletes the stored file. Access can also be removed at any time at myaccount.google.com/permissions.

Contact

Questions: open an issue at github.com/xtenduke/lkml-yt.
